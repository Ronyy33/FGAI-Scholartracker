**How to read it.** If adding history summaries does not improve on the snapshot, the past beyond the latest two semesters carries little extra information in this data, so no architecture (including an LSTM) can gain much from it. The gap between the snapshot and the oracle is the most any model using observable data could still gain; the oracle's own error is next-semester randomness that cannot be predicted at time t.
